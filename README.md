# KitchenCoach

KitchenCoach is a browser based recipe coach prototype. It helps a cook find a recipe, plan missing ingredients, and follow a step by step cooking session.

## Run locally

Install Node.js, then open a terminal in this folder and run:

```sh
node server.mjs
```

Open [http://127.0.0.1:4401](http://127.0.0.1:4401). The app uses plain JavaScript modules and has no package install step.

## What’s included

- Onboarding for cooking skill, dietary preferences, restrictions, and cuisines
- Recipe search and filters, with recommendations ranked by saved preferences and liked recipes
- Recipe details, serving size controls, shopping list selection, and a simulated pickup or delivery order
- Cook mode with a step timer and saved cooking history
- Browser local storage for demo data and preferences

The store inventory, checkout, order tracking, and account details are sample data. The prototype does not connect to real retailers, payments, location services, or notifications. Allergen notes are informational and may be incomplete; check ingredient packaging before cooking.
